# سوپرمارکت‌ها و هایپرمارکت‌های مازندران

اپلیکیشن وب برای جمع‌آوری و نمایش لیست سوپرمارکت‌ها، هایپرمارکت‌ها و فروشگاه‌های زنجیره‌ای استان مازندران، با داده‌های **نشان (Neshan Search API)** و **گوگل مپ (Google Places API)**. می‌توانید از یکی یا هر دو منبع استفاده کنید؛ نتایج دو منبع با هم ترکیب و تکراری‌ها حذف می‌شوند.

## امکانات
- لیست فروشگاه‌ها با جستجو در نام، آدرس و محله
- فیلتر بر اساس شهر و نوع (سوپرمارکت / هایپرمارکت / فروشگاه زنجیره‌ای)
- نمایش روی نقشه با خوشه‌بندی نقاط
- فیلتر بر اساس منبع (نشان، گوگل، یا هر دو)
- تلفن و امتیاز فروشگاه از گوگل (اختیاری)
- لینک مستقیم هر فروشگاه به گوگل مپ، نشان و بلد
- خروجی CSV سازگار با Excel (فارسی درست نمایش داده می‌شود)
- قابل نصب روی گوشی (اندروید و آیفون) و کار بدون اینترنت
- بدون وابستگی: فقط Node.js نسخهٔ ۱۸ یا بالاتر لازم است

## راه‌اندازی

### ۱. گرفتن کلید API نشان
1. در https://platform.neshan.org ثبت‌نام کنید.
2. یک کلید از نوع **سرویس** (Service) بسازید و سرویس **جستجو (Search)** را برایش فعال کنید.
   کلید با `service.` شروع می‌شود.

### ۲. گرفتن کلید API گوگل (اختیاری)
1. در https://console.cloud.google.com یک پروژه بسازید و برایش **حساب پرداخت (Billing)** فعال کنید.
2. سرویس **Places API (New)** را فعال کنید.
3. از بخش Credentials یک API Key بسازید (با `AIza` شروع می‌شود). بهتر است کلید را فقط به Places API (New) محدود کنید.

**هزینه:** گوگل برای هر سرویس مقداری استفادهٔ رایگان ماهانه دارد و بیشتر از آن هزینه می‌گیرد. قیمت‌ها و سقف رایگان فعلی را در صفحهٔ قیمت‌گذاری Google Maps Platform ببینید. حالت `--phone` (گرفتن تلفن و امتیاز) در ردهٔ گران‌تری حساب می‌شود.

### ۳. جمع‌آوری داده
هر منبعی که کلیدش را تنظیم کرده باشید استفاده می‌شود.
```bash
# فقط تعداد درخواست‌ها را نشان می‌دهد
npm run plan

# جمع‌آوری کامل از هر دو منبع
NESHAN_API_KEY=service.xxxx GOOGLE_MAPS_API_KEY=AIza... npm run collect

# جمع‌آوری سریع، فقط مرکز هر شهر
NESHAN_API_KEY=service.xxxx GOOGLE_MAPS_API_KEY=AIza... npm run collect:quick

# فقط یک منبع
NESHAN_API_KEY=service.xxxx npm run collect -- --only=neshan

# با تلفن و امتیاز از گوگل
GOOGLE_MAPS_API_KEY=AIza... npm run collect -- --phone
```
در ویندوز (PowerShell):
```powershell
$env:NESHAN_API_KEY="service.xxxx"; $env:GOOGLE_MAPS_API_KEY="AIza..."; npm run collect
```

تعداد درخواست‌ها:

| حالت | نشان | گوگل |
|---|---|---|
| کامل | ۲۲۲۲ | ۸۰۸ جستجو، با صفحه‌بندی حداکثر ۲۴۲۴ درخواست |
| سریع (`--quick`) | ۴۶۲ | ۱۶۸ جستجو، حداکثر ۵۰۴ درخواست |

پاسخ هر درخواست در `data/cache` ذخیره می‌شود. اگر اجرا وسط کار قطع شد (مثلاً به‌خاطر رسیدن به سقف روزانهٔ API)، دوباره اجرا کنید تا از همان‌جا ادامه دهد.
نتیجهٔ نهایی در `data/stores.json` ذخیره می‌شود.

### ۴. اجرای اپلیکیشن
```bash
npm start
```
سپس http://localhost:3000 را باز کنید. برای دیدن روی گوشی (در همان وای‌فای) آدرس IP کامپیوتر را بزنید، مثلاً `http://192.168.1.5:3000`؛ ولی برای نصب روی گوشی، انتشار آنلاین (پایین) لازم است.

## انتشار آنلاین و نصب روی گوشی

اپلیکیشن یک **PWA** است: بعد از انتشار روی اینترنت، روی گوشی مثل یک اپ نصب می‌شود و لیست فروشگاه‌ها بدون اینترنت هم باز می‌شود. (کاشی‌های نقشه فقط آن‌هایی که قبلاً دیده‌اید بدون اینترنت نمایش داده می‌شوند.)

### جمع‌آوری با یک دکمه (بدون کامپیوتر)
1. در مخزن: **Settings → Secrets and variables → Actions → New repository secret**
   - نام: `NESHAN_API_KEY` — مقدار: کلید نشان
   - (اختیاری) نام: `GOOGLE_MAPS_API_KEY` — مقدار: کلید گوگل
2. در تب **Actions**، «جمع‌آوری لیست فروشگاه‌ها» را انتخاب کنید و **Run workflow** را بزنید.
3. بعد از پایان، لیست خودکار در سایت منتشر می‌شود. خلاصهٔ نتیجه در صفحهٔ همان اجرا نمایش داده می‌شود.

### انتشار روی GitHub Pages (رایگان)
1. کد را در یک مخزن گیت‌هاب قرار دهید. برای GitHub Pages رایگان، مخزن باید **عمومی (Public)** باشد؛ یعنی لیست فروشگاه‌ها برای همه قابل دیدن است.
2. در مخزن: **Settings → Pages → Source** را روی **GitHub Actions** بگذارید.
3. داده را روی کامپیوتر جمع کنید (`npm run collect`) و فایل `data/stores.json` را commit و push کنید:
   ```bash
   git add data/stores.json
   git commit -m "به‌روزرسانی لیست فروشگاه‌ها"
   git push
   ```
4. بعد از یکی‌دو دقیقه سایت در آدرس `https://<نام‌کاربری>.github.io/<نام-مخزن>/` آماده است. برای هر به‌روزرسانی فقط مرحلهٔ ۳ را تکرار کنید.

### نصب روی گوشی
- **اندروید (Chrome):** سایت را باز کنید و دکمهٔ «نصب روی گوشی» بالای صفحه را بزنید، یا از منوی ⋮ گزینهٔ «Install app / افزودن به صفحهٔ اصلی» را انتخاب کنید.
- **آیفون (Safari):** دکمهٔ اشتراک‌گذاری را بزنید و **Add to Home Screen** را انتخاب کنید.

> اگر فایل‌های اپلیکیشن (`public/`) را تغییر دادید، مقدار `VERSION` در `public/sw.js` را یکی بالا ببرید تا گوشی‌ها نسخهٔ جدید را بگیرند. برای به‌روزرسانی فقط داده، این کار لازم نیست.

## نحوهٔ جمع‌آوری
- ۴۲ شهر مازندران در `scripts/cities.js` تعریف شده‌اند. شهرهای بزرگ (ساری، بابل، آمل، قائم‌شهر) با شبکهٔ ۵×۵ و شهرهای متوسط با شبکهٔ ۳×۳ نقطه جستجو می‌شوند، چون هر جستجوی نشان فقط تعداد محدودی نتیجهٔ نزدیک برمی‌گرداند.
- عبارت‌های جستجو در نشان: سوپرمارکت، هایپرمارکت، فروشگاه زنجیره‌ای، افق کوروش، شهروند، رفاه، اتکا، هایپراستار، جانبو.
- در گوگل: سوپرمارکت، هایپرمارکت، فروشگاه زنجیره‌ای و supermarket، هر کدام محدود به مستطیل اطراف نقطهٔ جستجو، تا ۳ صفحه (۶۰ نتیجه).
- نتایج خارج از مازندران، موارد نامرتبط (پوشاک، موبایل و…) و فروشگاه‌هایی که گوگل «بستهٔ دائمی» اعلام کرده حذف می‌شوند.
- فروشگاه‌های تکراری یکی می‌شوند: نام یکسان در فاصلهٔ کمتر از ۱۵۰ متر، یا نامی که شامل دیگری است (مثل «افق کوروش» و «فروشگاه افق کوروش») در فاصلهٔ کمتر از ۶۰ متر. منبع‌های هر فروشگاه در لیست نمایش داده می‌شود.
- شهر هر فروشگاه بر اساس نزدیک‌ترین مرکز شهر تعیین می‌شود.

برای افزودن شهر یا عبارت جستجو، `scripts/cities.js` یا آرایهٔ `terms` در `scripts/providers/neshan.js` و `scripts/providers/google.js` را ویرایش کنید.

## محدودیت‌ها
- هیچ منبعی لیست صددرصد کامل نمی‌دهد. سوپرمارکت‌های کوچکی که در نشان یا گوگل ثبت نشده‌اند در لیست نخواهند بود.
- اگر یک فروشگاه در دو منبع با نام خیلی متفاوت ثبت شده باشد (مثلاً فارسی و انگلیسی)، ممکن است دو بار در لیست بیاید.
- تشخیص نوع فروشگاه بر اساس نام است و ممکن است در چند مورد دقیق نباشد.
